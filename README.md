#🏠 House Price Prediction

A machine learning project to predict house prices using regression models.

## 📌 Project Overview

The project includes:

- Exploratory Data Analysis (EDA)
- Outlier detection and treatment
- Feature engineering
- Log transformation
- Train-test split
- Feature scaling

## 🤖 Models Used

- Linear Regression
- Polynomial Regression
- Ridge Regression
- Lasso Regression

## 📊 Model Evaluation

Models are compared using:

- **R² Score** — higher is better
- **MAE** — lower is better
- **MSE** — lower is better

## 🛠️ Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 📁 Files

- `house_price_prediction.ipynb` — complete analysis, preprocessing, model training, and evaluation.
